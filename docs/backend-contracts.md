# 与现有后台的接口合同（待逐项核对）

此文档用于后续联调，不阻塞独立客户端工程、导航、页面和本地状态开发。某项功能进入接入阶段时，再确认其所需合同、测试环境和脱敏样例。

此表定义 App 所需语义，不声称后台目前已有同名端点。联调时记录实际路由、请求／响应 schema、错误码、鉴权方式、限流与 API 版本；不要按本表虚构 URL。

| 能力 | 客户端所需结果 | 服务端待确认／补齐 |
| --- | --- | --- |
| 邮箱验证、注册、登录 | 邮箱验证流程、会话恢复、过期和退出 | 原生客户端认证合同；避免套用浏览器同源 Cookie／Origin 语义；设备会话撤销 |
| 当前资源 | 套餐、有效期、额度、已用／剩余、采集时间与新鲜度 | 未采集／过期状态、服务开通中、冻结和到期错误码 |
| 商品目录 | 可售商品 ID、价格、币种、期限、每周期流量 | 报价版本、购买前二次确认、商品上下架 |
| 购买 | 幂等创建、订单 ID、处理中／成功／失败 | 超时重查、重复提交返回同一结果、交付状态 |
| 钱包充值 | 支付方式、充值订单与到账状态 | 与商品订单分离；支付回跳后服务端查询 |
| 线路列表 | 当前账户授权线路、展示名、区域、可用／维护 | 只返回消费所需字段，不返回管理密钥 |
| 连接配置 | 授权线路的短期／可轮换配置、过期时间 | 协议格式与客户端内核兼容、撤销、轮换、最小暴露 |
| 推荐 | 归因令牌／邀请码、归属与奖励状态 | 安装前后衔接、反作弊、归属争议与奖励结算 |
| 支持与公告 | 客服入口、维护通知 | 可配置渠道及故障通告 |

## 联调必需样例

每个接口至少准备成功、未登录、无权益、开通中、到期、额度不足、网络超时、重复请求样例；注明时间戳和单位。隐去真实凭据和用户数据。客户端与后台先约定稳定错误码，再写中文提示文案。

## 与 Portal 生命周期的关系

安卓接入后使用和 Portal 一致的账户、订单、交付、权益语义。此前引用的后台 Issue #438 仅作背景线索；联调前重新读取当前源代码和原生 Issue／PR，核对实际依赖及统一状态映射。任何客户端临时映射都需有服务端合同与迁移计划。
