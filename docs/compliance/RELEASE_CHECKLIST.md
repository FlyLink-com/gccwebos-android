# 开源发行放行清单

任何一项 BLOCKED 均不得发布正式许可证、源码包或 APK 发行声明。

## A. 版权与授权

- [ ] 在内部核实法定版权主体准确名称、司法辖区和权利证明；本 Draft 不要求公开披露身份，发行时版权声明的公开形式须经法律审查。
- [ ] 确认 Android 仓库原创代码权属。
- [ ] 核实历史贡献者、雇员、外包和共同作者的权利链。
- [ ] 商业双重授权 CLA/等效协议由所有相关权利人签署。
- [ ] 确认第三方代码未被错误纳入 FlyLink 商业再授权范围。

## B. 许可证与依赖

- [ ] 解析 releaseRuntimeClasspath、debug、test、androidTest 和 native Go 构建标签依赖。
- [ ] 生成精确版本、来源、校验值和许可证文本的 SPDX SBOM。
- [ ] 所有依赖许可证均有上游原文证据；无 NOASSERTION、UNKNOWN 或缺失项。
- [ ] 保留 Apache NOTICE、MIT/BSD 版权声明、MPL/LGPL 源码修改及其他义务。
- [ ] Mihomo 精确 Commit、archive SHA-256、本地补丁和 GPLv3 文本一致。
- [ ] 对 CMFA reference-only 来源完成相似性和发行物检查。
- [ ] 审查 GPL-3.0-only 项目目标与 GPL-3.0-or-later 文件级许可的组合口径。

## C. 品牌与资产

- [ ] 每个打包图片、角色、Logo、字标、字体、场景和图标均有原始文件/来源。
- [ ] 有作者、版权主体、转让或书面许可证据。
- [ ] 书面授权明确允许公开再分发、修改、商业使用及必要的再授权范围。
- [ ] 商标、品牌名称、第三方产品 Logo 的使用获得独立审查。
- [ ] 当前两份品牌清单中不一致的 hash 已核实并修正。
- [ ] 不存在未登记的 brand_* 资源。

## D. GPLv3 二进制发行

- [ ] 对 APK 中 GPL 组件的 Corresponding Source 范围完成法律和技术审查。
- [ ] 提供精确匹配 APK 的完整对应源码、补丁、构建脚本和安装说明。
- [ ] 记录 APK、SO、源代码包的 SHA-256 和对应 Git commit。
- [ ] 对 GPLv3 第 6 节适用的 User Product 场景评估并提供必要安装信息。
- [ ] App 内“关于 → 开源许可与第三方声明”可查看适当法律声明和许可证文本。
- [ ] 对外下载页/发布页明确提供源码获取方式。

## E. 最终批准

- [ ] 自动化 license audit 无阻断项。
- [ ] SPDX SBOM 经过独立核验。
- [ ] 品牌权利登记全部 APPROVED。
- [ ] 独立代码审查通过。
- [ ] 法律顾问审阅通过。
- [ ] 项目负责人明确批准正式许可证发布。
- [ ] 仅在上述条件全部满足后，才添加根 LICENSE 并合并正式发行 PR。

当前结论：BLOCKED。此清单未被勾选项不得解释为已完成。
