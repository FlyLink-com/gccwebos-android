# 节点页与本地加载：B 档实施记录

日期：2026-10-05。本文记录提交 `3423fcd` 的 B 档切片。范围：节点展示、测速入口、页面读取与套餐展示缓存；未改变配置存储格式或连接授权模型。

> 后续实现：节点传输延迟及失败重试改进见 [节点传输延迟](node-transport-latency.md)。下文保留 `3423fcd` 的行为与历史验收计数，不代表后续版本的测速结果。

## 已完成行为

- 节点页将当前**单个活动来源**展示为可折叠配置组，合并原来的大号已选节点卡。节点名称与协议采用紧凑两行，地区图标在左、真实延迟在右；长名称省略，正常字号行高至少 56dp，大字号允许增高。收起、展开不更改节点选择，也不下载订阅。
- 增加闪电测速图标，保留 48dp 触区与“测试节点延迟”无障碍标签，不增加可见按钮文案或测速解释。沿用现有并发、冷却、超时及结果期限；未取得成功结果时显示 `— ms`。
- 节点页每秒的展示、到期检查及延迟清理只检查进程内状态，不读磁盘或请求订阅。健康来源的导航校验在 IO dispatcher 执行本地读取，不重新下载；失效来源仍可通过再次进入页面触发恢复。实际测速及必要的来源重校验保留各自的 IO 路径，选择、连接仍执行完整授权检查。
- 套餐页使用专用目录读取。在没有待处理套餐订单的常见路径中，目录加载从钱包、充值报价、商品模型、商品列表共 **4 次 GET** 缩为商品模型与商品列表 **2 次 GET**。存在待处理套餐订单时，继续读取原订单状态；未知提交结果不会因进入套餐页而重新下单。
- 已读取的套餐卡片在同一已验证会话内保留于 AppShell 内存，切换页面后可立即展示。此缓存不跨进程冷启动、不提供离线商品交易能力；换账户或缺失会话身份时不读取旧缓存。缓存卡片在新一轮目录验证完成前不可购买，购买仍要求当前商品完整快照、新鲜报价及账户与前台门禁。
- 套餐页不再启动充值轮询。注册生命周期观察器时补发的首次 `ON_RESUME` 不重复加载；真实离开前台再返回时仍重新核验。未将价格、余额或账户有效期改为本地固定值。
