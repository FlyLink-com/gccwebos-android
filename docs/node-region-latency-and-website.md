# 节点地区、Ping 延迟和官网入口

## 范围

B 档应用变更，承接四页紧凑 UI。不修改服务端、认证模型、订阅格式准入、节点选择或内核启动条件。

节点页及连接页的当前节点使用本地地区图标。地区来自订阅名称里的明确国家/地区名、ISO 标记或国旗 emoji；不是 IP 地理定位。未知、冲突或异常标签使用地球图标。图标使用设备字体，不下载国旗或地理数据库。

连接页节点卡下增加官网玻璃卡片，显示 `gccwebos.com`，带轻量呼吸光效。只有点击才通过系统浏览器打开固定 `https://gccwebos.com`。系统关闭动画时保持静态；没有可用浏览器时显示重试提示。

## 延迟口径和边界

显示的是手机到节点服务器的 ICMP Ping 往返时间，不包含代理握手、代理转发或网站请求。未测显示 `— ms`，超时显示“未回应”，设备/网络不支持显示“暂不可测”；这些状态均不禁止正常选择和一键连接。节点页提供“测延迟”入口，无加载轴。

只从已完成严格校验、已知未到期的本地配置提取测速目标。目标只供 worker 使用，不显示、不记录、不写入新的持久化存储。测速不会刷新订阅、修改选择或 epoch、启动内核、创建 VPN 或改变购买资格。

探测使用 Android 应用自身的 ICMP datagram socket。DNS 和 socket 均绑定独立的当前物理网络 lease；网络改变即拒绝结果，不回退到默认或 VPN 路由。请求使用随机 nonce，核对 echo 类型、序号与 payload；取消后关闭 socket 和 lease。此实现沿用 API 30+ 的物理网络契约，API 26–29 如实显示不可测。

结果仅保存在内存，绑定不透明节点身份、账户 generation、物理网络和 120 秒有效期；最多四个并发，单项最多四秒，显式重测间隔 30 秒。测量前后重新检查本地配置，展示通过内存注册表遮蔽到期或失效结果。节点名称相同也不会串用数值。页面离开取消未完成任务，已完成有效值可用于连接页。
