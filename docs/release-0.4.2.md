## 发布说明草稿

### 新增与改进

- **订阅流量显示（#28、#31）**：未登录时，连接页显示订阅自带的用量（已用、总量、到期），标注“订阅提供 · 更新于 …”。
  导入的 YAML 订阅和账户订阅使用同一套规则，切换配置时显示当前配置自己的用量。缺字段、总量为 0 或全为 0
  一律视为未知，显示“暂未获取”。登录后仍优先显示账户接口的数据。用量只在导入、手动刷新、激活配置
  或账户订阅下载时更新，不做后台轮询。
- **节点选择保持（#29）**：订阅每次下载内容（字段顺序、剩余流量数字）变化时，不再清掉已选节点；
  只有节点被删除或其地址、凭据、名称真正变化时才需要重新选择。
- **信息行（#29）**：“剩余流量”“套餐到期”“官网”等订阅提示条目显示为只读信息行，不可选择、不参与测速，
  一键连接也不会随机选中它们。
- **配置编号（#29）**：新配置按已有“配置 N”的最大编号加 1 命名，不再重名。
- **配置组展开状态（#29）**：后台刷新后，已展开的配置组保持展开。

### 问题修复

- **YAML 表情解析（#30）**：修复节点名中的国旗等表情恰好落在解析器内部读取边界时，导入或刷新报
  “配置格式或协议不受支持”的问题。

### 已知限制

- 未包含原生会话自动续期（#26）。原生会话最长 30 分钟（服务端可设置更早到期），到期后需重新登录。
- 订阅提供的用量是参考值，来自订阅响应头；服务端在无数据时可能返回 0，客户端按未知处理。
- 第三方导入仅支持已实现的 SS / VLESS / Hysteria2 / TUIC 子集。

### 降级与回滚注意

- 0.4.2 写入的新本地格式（#28 导入配置的用量记录、#31 账户订阅缓存 v2）无法被 0.4.1 及更早版本读取，
  降级后会出现存储错误，需要重新同步账户订阅或重新导入配置。**请勿降级**；问题通过更高版本前向修复。
- 配置库 v3 的既有边界不变：不能靠降级或清除数据回滚。
