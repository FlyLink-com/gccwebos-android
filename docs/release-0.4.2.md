## 发布说明草稿

### 新增与改进

- **订阅流量显示（#28、#31）**：未登录时，连接页显示订阅自带的用量（已用、总量、到期），标注“订阅提供 · 更新于 …”。
  导入的 YAML 订阅和账户订阅使用同一套规则，切换配置时显示当前配置自己的用量。缺字段、总量为 0 或全为 0
  一律视为未知，显示“暂未获取”。登录后仍优先显示账户接口的数据。用量只在导入、手动刷新、激活配置
  或账户订阅下载时更新，不做后台轮询。
- **节点选择保持（#29）**：订阅每次下载内容（字段顺序、剩余流量数字）变化时，不再清掉已选节点；
  只有节点被删除或其地址、凭据、名称真正变化时才需要重新选择。
- **信息行（#29）**：“剩余流量”“套餐到期”“官网”等订阅提示条目显示为只读信息行，不可选择、不参与测速，
  一键连接也不会随机选中它们。
- **配置编号（#29）**：新配置按已有“配置 N”的最大编号加 1 命名，不再重名。
- **配置组展开状态（#29）**：后台刷新后，已展开的配置组保持展开。
- **导入订阅链接（#33）**：打开时不再自动弹出键盘；输入框内右侧新增粘贴图标，点一下即可从剪贴板填入链接。
- **导入后命名（#33）**：新导入的配置可立即命名（可跳过）；命名或重命名与已有配置同名时提示
  “已有同名订阅，请重新命名你的订阅”。
- **连接页·当前节点（#37）**：已连接时显示正在使用的节点名、地区旗帜和协议，以及实时下载/上传速度和延迟。
- **连接页·流量卡片（#36）**：进度条平滑展开、已连接时柔和发光，流量数字滚动更新，流量偏低或即将到期时颜色渐变提醒。
- **我的（未登录）（#38）**：使用正常页面布局，一键“去登录”，余额处提示“登录查看你的余额”。
- **我的（已登录）（#38、#46）**：账户卡片（遮罩邮箱或账户 ID、可复制 ID、绘制头像、套餐标签、会员有效期与续费入口）、
  独立余额卡片、分组菜单和邀请好友横幅；去掉重复的「我的钱包」入口。
- **套餐页（#39）**：全新玻璃卡片设计，“超值推荐”标识性价比最高的套餐，套餐权益一目了然，一键“立即购买”。
- **钱包充值（#40）**：全新充值页面，金额方块一目了然，支持查看余额明细和充值记录，一键“立即充值”。
- **邀请返利（#41）**：全新邀请页面，专属邀请链接一键复制，多渠道分享，推广收益一目了然。
- **我的订单 / 账单明细（#42）**：不透明历史卡片、今天/昨天日期分组、用户向状态文案；账单按业务事件一行展示，
  正负金额颜色区分。
- **全局动效（#43）**：按钮按压缩放与轻触感反馈、分段标签滑动指示、页签内容左右切换、加载骨架闪烁、更轻的底部面板。
- **连接页分区（#44）**：Hero 区集中展示连接状态、当前节点与电源按钮；套餐卡片抬头显示套餐徽章、到期日与续费入口；
  多平台链接更紧凑。
- **节点页与导入（#45）**：信息条展示流量/到期摘要；不透明顶栏与选中高亮；延迟色档与一键测速；
  导入改为底部面板（扫码 / 订阅链接 / 配置文件）。

### 问题修复

- **YAML 表情解析（#30）**：修复节点名中的国旗等表情恰好落在解析器内部读取边界时，导入或刷新报
  “配置格式或协议不受支持”的问题。

### 已知限制

- 未包含原生会话自动续期（#26）。原生会话最长 30 分钟（服务端可设置更早到期），到期后需重新登录。
- **历史限制，已被 #50 后续修复替代**：当时已选节点只在应用运行期间保留。正式 0.4.2 已记录节点选择持久化与覆盖升级后保留；不能继续把本条当作当前缺陷。
- 订阅提供的用量是参考值，来自订阅响应头；服务端在无数据时可能返回 0，客户端按未知处理。
- 第三方导入仅支持已实现的 SS / VLESS / Hysteria2 / TUIC 子集。

### 降级与回滚注意

- 0.4.2 写入的新本地格式（#28 导入配置的用量记录、#31 账户订阅缓存 v2）无法被 0.4.1 及更早版本读取，
  降级后会出现存储错误，需要重新同步账户订阅或重新导入配置。**请勿降级**；问题通过更高版本前向修复。
- 配置库 v3 的既有边界不变：不能靠降级或清除数据回滚。
