# 最初开发顺序与验收

## M0 仓库与合同

- 建独立私有仓库 `gccwebos-android`；保护主分支，PR 评审、秘密扫描、构建 CI。
- 创建 Android Studio 工程、Gradle wrapper、测试／发布构建变体、签名占位配置（密钥不入库）。固定 applicationId，确定最低 Android 版本与支持设备。
- 核对服务端当前 commit、Issue #438、真实 API 和订阅格式，形成脱敏契约样例。
- 产物：工程能在 CI 与本地构建空壳；接口合同签字确认。

## M1 真实 VPN 连接（最高优先级）

- `VpnService` 授权、前台服务、TUN 生命周期、内核适配、授权配置获取。
- 自动／手动线路、实际流量探测、断开、重连、网络切换和进程恢复。
- 真机验收：首次系统授权；连接后 DNS／网页／目标 API 可用；断开后路由恢复；切换 Wi-Fi／蜂窝后可恢复；撤销授权后准确提示；过期权益阻断新连接。
- 无可用内核或协议不兼容时停止发布，不用假连接代替。

## M2 账户与购买

- 邮箱验证、注册、登录、会话恢复、退出；服务端商品与报价；月卡／年卡购买和续费。
- 资源展示、购买／充值订单、钱包、开通中与失败状态。
- 验收：重复点击仅一笔订单；超时可恢复；支付回跳后重查；商品下架或价格变动重新确认；未知流量不显示零。

## M3 推荐与签名测试包

- 分享链接、邀请码、归因确认、奖励状态、支持入口、维护公告。
- 签名 APK、版本号、更新提示、隐私说明、崩溃与脱敏连接诊断。
- 验收：已安装／新安装的推荐路径；错误码到文案；至少两类 Android 设备与多个系统版本真机回归；安全审查和内核许可证核对。

## M4 Google Play 渠道（独立发布门槛）

- 评估具体国家／地区的付款规则；实现符合对应渠道要求的购买流程与服务端核验。
- 完成 `VpnService` 声明、数据安全、隐私披露、商店素材、内部测试与审核问题修正。

## 首轮任务拆分

1. Android 工程、构建与 CI。
2. 后台原生认证／权益／线路／配置合同审计与必要接口补齐。
3. 内核候选、协议兼容与许可证验证。
4. VPN 服务与连接状态机真机实验。
5. Compose 四入口与业务 API 接入。
6. 订单幂等和支付状态恢复。
7. 推荐归因及签名 APK 交付。

后端缺少的能力在 `proxy-gateway-minimal` 实现，Android 仓库只放客户端和契约测试样例。每个任务分别标记责任仓库、依赖项和验收证据。
