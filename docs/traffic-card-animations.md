# 流量卡状态动画（连接页）

只画不改值：动画只改变外观，不参与连接状态、准入或任何数字。

| 状态 | 外观 |
|---|---|
| 已连接 | 卡片边缘一圈平静的青色光（1.5 dp 边 + 柔光），α 0.22–0.40 缓慢起伏（2.8 s，EaseInOutSine） |
| 未连接 | 静态暗青边（α 0.14），不动 |
| 正常用量 | 进度条进入时填充一次（900 ms，原有），填满后约 260 ms 起一次从左到“前端”的高光掠过（640 ms，峰值 α 0.28，只在已填充部分内），不循环 |
| 流量低（剩余 < 10%，未用尽） | 进度条变琥珀色；条端光晕和「剩余流量」数字光晕共用一个 2 s 的慢呼吸（α 0.12–0.36）；数字为琥珀色（对比度 ≥ 4.5:1，有单测） |
| 已用尽（剩余 0） | 静态红色进度条；填充完成后只抖一次（280 ms，±3 dp，三个半周期） |

## 省电与可达性
- 减少动画（系统“移除动画”，`ANIMATOR_DURATION_SCALE` = 0）：不填充、不掠光、不呼吸、不抖动；已连接为静态 α 0.28 边，低流量为静态 α 0.22 琥珀光。
- 两个循环动画（已连接边光、低流量呼吸）只在「卡片在屏幕上可见（`onVisibilityChanged`，≥5%）+ App 处于 RESUMED + 动画未被关闭」时运行；离开屏幕或进入后台即停并回到静态值。
- 边光是单独的叠加层（自带 layer），一帧只重绘这一圈，不重绘卡片内容；所有逐帧值只在 draw / graphicsLayer 阶段读取，不引起重组。
- 无新依赖，只用 Compose。
- 阈值沿用已有的 `UsageCriticalRemainingFraction`（10%）；`usageCardState` 为纯函数（`UsageCardStateTest`）。
- 变化：原先 < 10% 的进度条是红色，现在低流量是琥珀色，红色只用于“已用尽”和“已到期”；原先已连接时条端的呼吸光由卡片边光取代。

## 设备验证（OPPO，并排包 `.debug.uitest`，未触碰官方包与 `.debug.acct`）
